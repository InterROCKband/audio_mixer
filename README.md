# 🎵 Mixer da Banda InterROCK

Um site simples e responsivo para **mixagem de faixas (stems)** da banda, permitindo que cada integrante possa **ouvir separadamente ou em conjunto** as trilhas de cada música, ajustando os volumes e usando funções de **Mute** e **Solo**.

> **Objetivo:** Facilitar os ensaios e estudos individuais, oferecendo uma forma prática de ouvir cada parte da música (vocais, guitarras, baixo, bateria, metrônomo, etc.) diretamente pelo navegador — **funciona também em celulares**.

---

## 🚀 Funcionalidades

- 🎚 **Sliders individuais** para controlar o volume de cada faixa.  
- 🔇 **Botão Mute** para silenciar qualquer track.  
- 🎧 **Botão Solo** para isolar uma única track.  
- ▶️ **Botões Play, Pause e Stop** para controle global da música.  
- ⏱ **Slider de tempo global** para avançar ou retroceder a música.  
- 📱 **Layout responsivo**, otimizado para desktop e celular.  
- 🌐 **Funciona direto no navegador**, sem precisar instalar nada.
